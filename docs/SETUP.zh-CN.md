# 单词守门：红米 K80 / 扇贝单词

这是**免 Root 的 AutoJs6 脚本版**，需要先在手机上安装 AutoJs6，然后运行脚本。它不是独立 APK，不能把 JS 文件直接当安装包安装。

按你的要求配置：学习扇贝时限制**抖音、小红书、哔哩哔哩、火影忍者手游**；**微信、QQ 保持可用**。应用包名从手机实际安装列表中选择，不预设未经核实的火影忍者或扇贝包名。

当前状态：电脑端已通过 21 项状态机测试和 5 项模拟 Android 对接测试；**尚未在目标红米 K80 / HyperOS 3.0.307.0 和当前扇贝版本上真机验证**。识别规则需要在手机上采集，不能只凭公开资料猜扇贝页面。

## 1. 把脚本放到手机

1. 从 [AutoJs6 官方发布页](https://github.com/SuperMonster003/AutoJs6/releases)获取手机适用的稳定版安装包。这里使用的是维护中的 AutoJs6，不是早已停止维护的旧 Auto.js 4。
2. 将本文件夹中的 `WordGate.js`、`FocusCore.js`、`StartGuard.js` 一起传到手机同一个文件夹，例如 `Download/Shanbay-Focus/`。也可以把 ZIP 传到手机后解压。不要只复制一个 JS 文件。
3. 在 AutoJs6 的脚本文件列表中进入该文件夹，运行 **`WordGate.js`**。若运行器版本要求先导入脚本文件夹，先在文件管理中选择该目录。

## 2. 手机端开启权限

- **无障碍服务**：允许 AutoJs6 读取当前扇贝页面及执行返回桌面的动作。
- **显示在其他应用上层 / 悬浮窗**：供校准选择窗口和提示使用。AutoJs6 的非 UI 脚本对话框可能依赖此权限。
- 在系统设置搜索 **自启动、后台自启动、省电策略、后台弹出界面**，允许 AutoJs6 后台运行，省电限制设为“不限制”（如果系统提供该选项）。必要时在最近任务中锁定 AutoJs6，减少被清理。
- 若系统针对侧载应用提示“受限设置”，只通过应用信息页面提供的系统入口允许该应用使用相关权限；不要通过来路不明的工具修改系统。

这些设置的实际入口以你手机为准。小米官方说明了后台自启动设置，但不保证所有版本菜单完全相同：[小米后台自启动说明](https://www.mi.com/uk/support/faq/details/KA-507611/)。Windows 上的 Codex 管理员权限不会赋予手机 Root 权限。

## 3. 选择应用名单

运行 `WordGate.js`，选择 **配置学习软件和四个娱乐应用**。

- 学习软件选实际安装的**扇贝单词**，不要选扇贝阅读/听力。
- 对四个娱乐应用逐一确认实际安装版本；找到多个版本时自行选择要限制的版本。
- 没有找到的应用会明确列出，并且不会被声称已锁住。双开、隐私空间、工作资料中的其他副本需要另行适配。
- 微信、QQ、电话、系统设置、桌面以及 AutoJs6 自身不在拦截范围，白名单优先。

## 4. 采集两个真实页面（关键步骤）

脚本必须知道你当前扇贝版本中，哪种画面表示“开始学习”，哪种画面表示“今日全部目标完成”。没有配置完成规则时，脚本不会启用拦截。

### 采集学习中页面

1. 在菜单选 **采集学习中页面**。
2. 阅读提示后点确定，在 **15 秒**内切到扇贝，真正开始学习，停在单词学习画面。
3. 采集后脚本会尝试返回 AutoJs6 并显示文字选择框。选择 **2～6 个稳定文字**，例如该页面实际存在的学习操作按钮。不要选当前单词、释义、计数等会变化的内容。
4. 不要把首页“开始学习”按钮当学习中规则，否则只是打开首页就可能触发锁定。

### 采集今日全部完成页面

1. 先正常完成一次当天所有要求的新词和复习任务。
2. 回到脚本菜单选 **采集今日目标全部完成页面**，再在 15 秒内切到对应结果画面。
3. 选 **2～6 个共同证明“今日全部任务已完成”的稳定文字**。必须包含今日/今天的上下文以及完成语义；不要选“完成一组”、单独的“完成”、打卡按钮或历史打卡记录。
4. 如果页面文字不足、界面只以图片呈现、规则同时命中两个阶段，脚本会拒绝保存或识别。不要编造规则强行开启。

首次校准通常需要先完整学完一天，次日才能走通完整试运行。采集本身是配置动作，不会开始正式拦截。

## 5. 先试运行，再启用正式模式

1. 默认是**试运行**，选择“开始守护”。
2. 真正进入扇贝学习画面，停留至少约 1.2 秒，确认出现“已识别开始学习”提示。
3. 切换到四个娱乐应用，确认有“试运行：这里会拦截娱乐应用”的提示。试运行只提示，不把应用退回桌面。
4. 确认微信、QQ 不受影响。
5. 完成今日**全部**目标，停留在采集过的完成画面至少约 1.2 秒，确认出现今日完成提示。完成前不能提前出现此提示。
6. 重新运行菜单，选“停止本脚本”，稍等约 1 秒，再把运行模式改成**正式拦截**。脚本只在试运行识别到开始和完成之后允许启用正式模式。
7. 再次选“开始守护”。正式模式会在学习开始后，将尝试打开的指定娱乐应用退回桌面，直到识别到今日全部完成。

修改应用名单或重新采集规则后，必须重新试运行。正式学习状态保留在本地，退出扇贝、停止后再运行、跨午夜不会自动清除未完成状态。同一天已识别完成后继续学习，不再次上锁；次日开始新学习后可以重新上锁。

## 6. 每天怎么用

- 首先确保 AutoJs6 无障碍和守护脚本在运行。
- 然后打开扇贝并真正开始学习；不用手动切换系统应用锁。
- 完成当日新词、复习等目标后，保持对应完成页面可见，脚本才有机会检测并解除限制。
- 配置完成后可以运行 `StartGuard.js` 直接启动守护；它也可作为 AutoJs6 自身支持的开机/定时任务入口。**是否能在开机后自动拉起、是否被 HyperOS 清理，需要实机检查，脚本不保证自行复活。**

## 7. 能力边界与恢复

- 这是本机自愿使用的**拦截式自律锁**：通过无障碍读取前台应用，命中四个名单时返回桌面；不修改小米系统应用锁，不挂密码，不使用 Root、不禁用应用包。
- 手机所有者仍可关闭无障碍、停止脚本、清除数据或卸载运行器，不能承诺“绝对无法绕过”。设置和电话始终可访问。
- 脚本不自动帮你背词、不点完成、不操作账号或未公开接口。完成识别来自本机可见页面，不是扇贝服务器提供的认证结果，因此需要实机校准，扇贝改版后也要重新检查。
- 锁屏时不采集、不执行拦截。系统关闭无障碍或杀死运行器后，拦截会失效；未完成状态仍会在下次运行时恢复。
- 若误识别或脚本异常，先在 AutoJs6 停止本脚本/关闭其无障碍，再检查规则。停止守护不会删除已保存的未完成学习状态。

## 8. 页面识别失败时

运行 **导出扇贝页面信息（适配诊断）**，根据提示切到学习页或真正的今日完成页。脚本把可见文字保存为同目录 `shanbay_snapshot.json`。不联网、不自动上传；只遍历已选择的扇贝，不读取微信或 QQ 聊天内容，跳过密码字段。

导出的文字可能包括昵称、当前单词和学习进度，分享前检查。可以提供这个文件，或提供“学习中页面”和“今日全部完成页面”两张截图，进一步适配你的扇贝版本。

## 9. 文件及验证

- `WordGate.js`：手机配置入口、校准、前台应用拦截和状态持久化。
- `FocusCore.js`：纯 JavaScript 状态机；DeepSeek 初稿，经 GPT/Codex 修正和验收。
- `StartGuard.js`：配置完成后的直接启动入口。
- `test_focus_core.js`、`test_runtime.js`：电脑端测试，不在手机上运行。
- `验证记录.txt`：本次测试的实际输出。
