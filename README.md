# shanbay-focus

基于 AutoJs6 的手机学习专注脚本：检测到开始背词后启动娱乐应用拦截，在“今日全部完成”页解锁。适用于抖音、小红书、B站、火影忍者等应用在今日目标完成前的使用拦截，微信、QQ 放行。

> 本项目为 AutoJs6 脚本工程，不是 APK。默认使用 `dryRun` 仅提示，不执行 HOME 返回桌面。

## 快速开始

1. 安装 [AutoJs6](https://github.com/SuperMonster003/AutoJs6)，导入本仓库脚本。
2. 运行 `WordGate.js`，通过菜单选择实际安装的扇贝和娱乐应用，无需修改源码。
3. 运行前，在真机上手动采集：
   - 学习中页面至少 2 个不同且稳定的精确文字；
   - “今日全部完成”页面至少 2 个不同且稳定的精确文字。
4. 先以默认 `dryRun` 模式走完“开始学习 → 今日完成”全流程，确认识别与提示正确。
5. 再启用正式 HOME 返回桌面拦截。

详细步骤见 [docs/SETUP.zh-CN.md](docs/SETUP.zh-CN.md)。

## 识别规则

- 同一屏连续稳定 1200ms，且至少 3 次采样一致，才判定状态。
- 未完成状态跨日、重启后持久化保存。
- 无障碍服务或脚本进程被停用时，拦截会失效。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `WordGate.js` | 配置入口：包名、应用名单、识别文字 |
| `FocusCore.js` | 专注状态机 |
| `StartGuard.js` | 直接守护入口 |
| `test_focus_core.js` | 状态机 Node 测试 |
| `test_runtime.js` | 运行时模拟测试 |
